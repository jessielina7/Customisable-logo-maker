# 🎨 Customizable Logo Generator

A customizable Android application that generates unique text-based logos from user input. Users can enter a name, select the number of letters to include, and instantly generate a personalized logo based on their preferences.

## ✨ Features

- Enter any name or text
- Choose how many letters to use in the logo
- Instantly generate a customized logo
- Clean and user-friendly interface
- Fast and responsive performance

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- Gemini API
- Google AI Studio
- Material Design

## 🤖 AI-Assisted Development

This project was developed with the assistance of **Google AI Studio (Gemini)**. AI was used to help with code generation, debugging, implementation, and development guidance. The application was customized, tested, and refined to achieve the desired functionality.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Create a `.env` file and add your Gemini API key:

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

4. Build and run the application on an Android device or emulator.
